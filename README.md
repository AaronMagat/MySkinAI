# MySkinAI

An independently maintained copy of the SkinGuard project, based on the collaborative PythonSkin project. Original project: https://github.com/Gcan3/PythonSkin. Source ownership and contribution history remain with the original contributors; modifications in this repository are maintained separately.

## Setup

See `requirement.txt` for dependencies. The original project documentation describes running the Flask application with `python app.py` after preparing the model.

## Important

This project provides experimental image classification and is not a medical diagnostic tool.
